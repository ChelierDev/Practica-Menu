📌 About the Project

Practica Menu is an educational project developed as part of the Web Applications subject by students in the first year of SMR (Microcomputer Systems and Networks).

The main purpose of this project is to practise and improve basic web development skills through a practical assignment.

🎯 Purpose

This project was created for educational purposes, allowing students to apply the knowledge and skills acquired during their Web Applications classes.

🏫 Educational Context
Course: 1st Year of SMR (Microcomputer Systems and Networks).
Subject: Web Applications.
Project Type: Practical Assignment.
Purpose: Learning and practising web development.
🛠️ Technologies

Web technologies used in this project.

📚 Disclaimer

This repository is part of a school assignment. It has been created exclusively for educational and learning purposes by students of the Web Applications subject in the first year of SMR.
